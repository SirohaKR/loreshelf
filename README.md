# LoreShelf — 내 캐릭터 서재

게임·캐릭터 챗봇을 기획하면서 만든 캐릭터와 세계관을 한곳에 모아 두는 개인용 아카이브예요.
PC와 휴대폰 화면 모두에서 쓸 수 있어요.

> 지금은 **1단계(작업실)**까지 만들어져 있어요. 이미지 프롬프트 기록, 챗봇 설정, 공개 블로그는 다음 단계예요. 단계 계획은 아래 "로드맵" 참고.

## 할 수 있는 것 (v0.2)

- **캐릭터**: 기본 정보 칸(🔒 비밀 칸 표시), 성격 축, 대표 대사, 태그, 배경 이야기(마크다운), 테마색, 대표 이미지, 갤러리
- **저장 위치**: 프로젝트 전용으로 두거나 공용 서재에 두고 여러 프로젝트에 "연결". 서재로 꺼내기·다른 프로젝트로 옮기기·프로젝트용으로 분기(복사)
- **프로젝트**(게임 / 챗봇 / 기타): 소개, 세계관 설명, 진행도, 속한 캐릭터 보기
- **장르·세계관 태그**: 로판·현판·학원·청춘·복수 등 130여 개 기본 태그에서 골라 프로젝트에 붙이고, 태그로 거르기
- **검색**: 이름·소개·태그·기본 정보·대사·배경 이야기를 한 번에
- **휴지통**: 지운 것 되살리기 / 영구 삭제
- 밝게·어둡게 화면, 로그인(1인용)

## 개발 환경

- Dart SDK 3.11 이상 (서버), Flutter 3.47 이상 (앱)
- 화면은 HTML · CSS · 바닐라 JS (빌드 도구 없음)
- DB는 SQLite 파일 하나

## 로컬에서 실행

```bash
cd server
dart pub get
dart run bin/server.dart
```

브라우저에서 `http://localhost:5000` → 처음 접속하면 주인 계정을 만들어요 (계정은 하나만).

## 앱 (Flutter, 보기 전용 · 1차)

`app/`에 Windows·Android·웹으로 띄울 수 있는 앱이 있어요. 로그인, 홈, 캐릭터 목록(전체/서재/프로젝트별)·상세(프로필·갤러리), 프로젝트 목록·상세(장르 태그)를 볼 수 있어요. 편집은 다음 단계예요.

```bash
cd app
flutter run -d windows
```

로그인 화면의 서버 주소에 `http://localhost:5091`(개발 서버)이나 `http://<NAS 주소>:5090`을 넣어요. 자세한 건 [app/README.md](app/README.md), Flutter 공부용 설명은 [docs/flutter-공부노트.md](docs/flutter-공부노트.md).

## Docker / NAS에서 실행

```bash
mkdir -p data
docker compose up -d --build
```

`http://<NAS 주소>:5090` 으로 접속해요. DB와 올린 이미지는 `data/` 폴더에 남아서 다시 빌드해도 그대로예요.

## 설정 (환경 변수)

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `PORT` | `5000` | 서버 포트 |
| `DB_PATH` | `data/loreshelf.db` | SQLite DB 파일 |
| `ASSETS_DIR` | `data/assets` | 올린 이미지 폴더 |
| `MIGRATIONS_DIR` | `migrations` | DB 변경 파일 폴더 |
| `WEB_DIR` | `web` | 작업실 화면 파일 폴더 |

## 백업

`data/` 폴더 하나만 복사하면 돼요 (`loreshelf.db` + `assets/`).

## 로드맵

| 단계 | 내용 |
|---|---|
| **1 (지금)** | 캐릭터·세계관·프로젝트, 전용/서재 캐릭터, 이미지, 검색, 반응형 화면 |
| 2 | 이미지·프롬프트: 고정 프롬프트, 생성 기록(플랫폼·모델·LoRA), 프롬프트 자동 분류, PNG 생성 정보 읽기 |
| 3 | 챗봇 설정 + 캐릭터 카드 V2/V3 내보내기 |
| 4 | 공개 블로그 (비밀 칸은 서버에서 빼고 보냄) |
| 5 | 관계도, 타임라인, 버전 기록, 게임 데이터, 기획 보드 |
| 6 | Claude API 보조 기능, Civitai 조회, 로컬 WebUI 연동 |
