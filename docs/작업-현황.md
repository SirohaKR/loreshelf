### 2단계 남은 것

- **Flutter 앱**: 이미지·프롬프트는 보기·복사만 됨(v0.3.1). 만들기·고치기, PNG 올려서 생성 정보 읽기(shared의 `readGenerationInfo`를 앱에서 바로 쓸 수 있음), 생성 도구 화면은 아직. 실제 기기에서 탭을 띄워 보는 건 못 해 봄(위젯 테스트만).
- Civitai 조회: WebUI PNG의 `Model hash`·`Lora hashes`(생성 기록 `extra`에 들어 있음)로 이름·페이지 자동 채우기 — 6단계와 겹침.
- "AI로 분류"(문장형 Midjourney 프롬프트) — 6단계 Claude API 때.
- 태그 사전 확장(Danbooru 태그 CSV), 고정 프롬프트 태그를 화면에서 하나씩 끌어 옮기기(지금은 프롬프트 글로 고침).
- 생성 기록 삭제는 휴지통을 안 거침 (스키마엔 `deleted_at`이 있으니 나중에 휴지통에 넣을 수 있어요).
- NovelAI의 "알파 채널에 숨긴 정보"(stealth pnginfo)는 아직 못 읽어요.

### Flutter 앱

- 편집 기능 전부 (캐릭터·프로젝트 만들기/고치기, 이미지 올리기, 태그 고르기)
- 서재/휴지통/검색 화면

### 알려진 문제·확인 못 한 것

- Docker 이미지 빌드는 아직 로컬에서 직접 해 보지 못했어요 (`dart build cli` 실행 파일은 동작 확인). NAS에선 설치해서 쓰는 중.
- v0.3.0부터 Dockerfile이 `shared/` 폴더도 복사해요. NAS에서 처음 업데이트할 때 빌드가 되는지 확인이 필요해요 (로컬 Docker로는 아직 못 해 봄).
- 한글·긴 경로에서 `flutter analyze`, `flutter build windows`가 실패할 수 있어요 → 아래 4절.
- 앱 웹 버전 첫 로딩 때 한글 글꼴을 받는 동안 글자가 잠깐 ☒로 보여요.

## 3. 새 PC에서 시작하는 법

1. **설치**: Flutter SDK 3.47 이상(Dart 3.11 이상이 같이 들어 있어요), Git. 크롬이나 엣지(목업 스크린샷용, 선택).
2. **받기**: `git clone https://github.com/SirohaKR/loreshelf.git` — 이 저장소에만 커밋 계정을 쓰려면 `git config user.name ...`을 저장소 안에서(전역 말고) 설정.
3. **패키지**: 저장소 맨 위에서 `dart pub get` (작업 공간이라 `server`·`app` 둘 다 받아요).
4. **개발 서버** (`server/`에서):
   ```bash
   PORT=5091 DB_PATH=data/dev.db ASSETS_DIR=data/assets dart run bin/server.dart
   ```
   PowerShell이면 `$env:PORT='5091'; $env:DB_PATH='data/dev.db'; $env:ASSETS_DIR='data/assets'; dart run bin/server.dart`.
5. **개발 계정 다시 만들기**: `server/data/`는 저장소에 안 올라가요. 새 PC에선 `http://localhost:5091`에 처음 접속하면 주인 계정 만들기 화면이 나와요 → 아이디 `dev`, 비밀번호는 새로 정해서 `private/dev-account.md`(git에 안 올라감)에 적어 둬요. 앱의 실서버 테스트는 이 비밀번호를 `LORESHELF_LIVE_PASSWORD`로 넘겨요.
6. **앱 코드 생성**: freezed·riverpod 파일을 고치면 `app/`에서 `dart run build_runner build --force-jit` (한글 경로에선 `--force-jit` 필수).
7. **테스트**: `server/`에서 `dart test`, `app/`에서 `flutter test`.
   - **Windows에서 서버가 켜져 있으면 sqlite3.dll이 잠겨서 `dart test`가 실패해요.** 개발 서버(포트 5091)를 끄고 테스트한 뒤 다시 켜요.
8. **ERD 다시 그리기**: DB를 바꾸면 `server/`에서 `dart run tool/make_erd.dart` → `docs/erd.html`.

### NAS(Docker) 설치·업데이트

```bash
# 처음
git clone https://github.com/SirohaKR/loreshelf.git loreshelf
cd loreshelf
mkdir -p data      # Synology는 bind-mount 폴더를 자동으로 안 만들어요
docker compose up -d --build

# 업데이트 (DB 변경은 서버가 켜질 때 자동 적용 — 그 전에 data/ 백업 권장)
git pull
docker compose up -d --build
```

## 4. 작업 규칙 (요약)

자세한 건 [개발자-설명서.md](개발자-설명서.md)와 [DB-설계.md](DB-설계.md).

- SQL은 `*_repository.dart`에만, 값 검사는 `*_routes.dart`에서.
- DB 변경은 **새 번호 마이그레이션 파일**로만 (기존 파일 수정 금지). 이름 규칙은 `server/test/schema_rules_test.dart`가 자동 검사.
- 웹 화면은 바닐라 JS, `html\`\`` 템플릿(자동 이스케이프)으로만 그려요.
- 앱은 `lib/core` + `features/<기능>/{data,domain,presentation}`, Riverpod 코드 생성 + hooks + freezed. 설명은 [flutter-공부노트.md](flutter-공부노트.md).
- UI: 플랫하게, 그라데이션 없이, 라이트/다크 둘 다.
- 보이는 변경마다 [CHANGELOG](../server/CHANGELOG.md)에 버전을 올려 사용자 입장의 한국어로 적어요.
- 공개 저장소예요: 실명·NAS 주소·비밀번호는 `private/`(git 제외)에만 둬요.
- 한글 경로 문제: `build_runner`는 `--force-jit`, `flutter analyze` 대신 `dart analyze`, `flutter build windows`는 경로가 너무 길면 실패 ([app/README.md](../app/README.md)).
