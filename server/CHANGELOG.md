## v0.3.8 — 2026-10-16 · 챗봇 설정 준비 (화면은 다음 버전)

- 3단계 **챗봇 설정**의 바탕을 깔았어요. 아직 화면에선 보이지 않아요(작업실 화면은 다음 버전 3-2).
- 챗봇은 이제 **작품(스토리) + 카드 13종**(스토리·인물·유저·이미지·매크로·**기타 인물**·프리셋 노트·변수·업데이트 규칙·트리거·상태창·업적·허브)을 **선으로 잇는** 모양으로 저장돼요. 한 캐릭터로 작품을 여러 개 만들 수 있어요. 새 작품을 만들면 가운데 스토리 카드가 같이 생겨요.
- 로판AI·로플챗 **칸별 글자 수 한도 표**(기준일 2026-10-16)와, `{{char}}`·`{{user}}`·`{{var_이름}}` 표기를 찾고·고치고(`{{Char}}`, `{user}`, `<char>`, `{{캐릭터}}` → 바른 표기)·플랫폼별로 바꾸는(로플챗은 `{{char}}` → 캐릭터 이름) 기능을 서버·앱이 같이 쓰는 곳에 만들었어요.
- 쓰지 않던 예전 챗봇 표 4개(카드 한 장 모양)는 지웠어요. 데이터가 없던 표라 지워지는 내용은 없어요. 그래도 NAS 업데이트 전엔 늘 하던 대로 `data/` 백업을 권해요.

## v0.3.7 — 2026-10-16 · 프롬프트 자동 분류 개선, 고정/이번만 나눠 저장, 네거티브 세트

- **자동 분류가 훨씬 똑똑해졌어요.** 영어 태그를 쉼표로 늘어놓은 긴 프롬프트도 거의 다 맞는 칸에 들어가요: 선화·채색·디테일(`bold lines`, `fine linework`, `sharp outlines`, `highly detailed`, `2D` …), 얼굴형·눈매·턱선(`slender face`, `sharp jawline`, `droopy eyelids`, `handsome` …), 구도·시점(`chest-up`, `front view`, `slight head tilt`, `character fills the frame` …), 의상(`vest`, `cravat`, `necktie`, `blouse` …).
- **동작이 먼저**예요: `giving flowers`, `offering bouquet`, `bouquet in front of chest`처럼 동작·자세를 나타내는 태그는 배경이 아니라 포즈·구도로 가요.
- 새 칸 **성격·분위기**(`shy`, `quiet`, `cheerful`, `cold`, `gentle`, `… impression`, `… aura` 등)와 **소품**(꽃다발·장미·리본·책·우산·검 …)이 생겼어요. 꽃은 들판·정원이 아니면 소품으로 들어가요. 예전 "의상·소품" 칸은 이제 **의상**이에요.
- 붙여넣기 결과의 칸마다 **고정 / 이번만**을 고를 수 있어요. 기본은 인물·외형·성격·분위기·의상·화풍·품질 = 고정(캐릭터의 고정 프롬프트), 표정·포즈·배경·소품 = 이번만(생성 기록).
- **고정 / 이번만 나눠서 저장**: 어느 고정 프롬프트에 어떤 태그가 추가되는지 먼저 보여 주고 확인받아요. 이미 들어 있는 태그는 다시 넣지 않아요. 나머지 장면 태그는 이어서 생성 기록으로 저장해요.
- 태그 칩에 **✕**가 생겼어요. 웹은 마우스를 올리면, 앱·모바일은 칩을 누르면 나와요. 붙여넣기 결과·고정 프롬프트·생성 기록 모두 돼요.
- **모든 캐릭터 공통 기본값**: 높은 품질을 위해 늘 넣는 품질 태그(`masterpiece`, `best quality` …)와 네거티브(`lowres`, `bad hands`, `watermark` …)를 캐릭터마다가 아니라 **한 번만** 저장해요. "이미지·프롬프트" 탭의 **모든 캐릭터 공통 기본값** 칸에서 보고, ✕로 빼고, 글로 더할 수 있어요.
- 프롬프트를 붙여 넣으면 공통 기본값과 **겹치는 태그는 빼고** 그 캐릭터만의 태그만 고정 프롬프트·생성 기록에 들어가요. 무엇을 뺐는지는 아래에 작게 보여 줘요. 화풍(`anime style` 등)은 캐릭터마다 다를 수 있어서 빼지 않아요.
- **전체 복사**(SD·NovelAI 형식)와 생성 기록의 **프롬프트 복사**는 공통 기본값 + 고정 프롬프트 + 기록을 합쳐서 내보내요 (겹치는 태그는 한 번만).
- **네거티브 세트**: 품질 / 손·해부학 / 글자·워터마크 / 얼굴 / 기타 묶음을 눌러서 공통 기본 네거티브에 한 번에 넣어요. 웹의 **세트 관리**에서 내 세트를 만들고 고칠 수 있어요.
- 앱: 캐릭터의 "이미지·프롬프트" 탭에 **공통 기본값** 칸과 **붙여넣기 → 고정 / 이번만 나눠서 저장** 칸이 생겼고, 칩 ✕도 웹과 똑같이 써요.

## v0.3.6 — 2026-10-15 · 앱에서 고정 프롬프트·생성 기록 만들기·고치기

- 앱의 "이미지·프롬프트" 탭에서 **고정 프롬프트**를 만들고 고칠 수 있어요. 이름 + 프롬프트 글 붙여넣기 → **자동 분류**(웹과 같은 shared 규칙) → 분류 결과 미리 보기, 네거티브·LoRA도 같이 고쳐요.
- **생성 기록**도 앱에서 만들고 고쳐요: **+ PNG로 가져오기**(사진을 고르면 올리고, WebUI/Forge·NovelAI·ComfyUI 생성 정보를 자동으로 읽어서 채워요) 또는 **+ 직접 기록**. 제목·플랫폼·모델·연결된 고정 프롬프트·시드·샘플러·스텝·CFG·크기·메모를 고치고, **★ 대표로**·**지우기**도 돼요.
- LoRA는 "생성 도구" 사전(웹에서 등록)에서 골라 붙여요. 고정 프롬프트는 사전에 없는 LoRA 이름은 저장할 때 빠지고, 생성 기록은 모르는 이름도 그대로 저장돼요 (서버와 같은 규칙).
- 아직은: 플랫폼·모델·LoRA·내 분류 사전을 앱에서 직접 등록·수정하는 "생성 도구" 화면, 붙여넣은 태그를 칸마다 끌어 옮겨 사전을 가르치는 것은 웹에서만 돼요.

## v0.3.0 — 2026-10-15 · 이미지·프롬프트

- 캐릭터 화면의 **이미지·프롬프트** 탭이 열렸어요.
- **프롬프트 붙여넣기 → 자동 분류**: WebUI·Forge 생성 정보 통째로, NovelAI 태그, Midjourney 명령어를 붙여넣으면 인물·외형 / 의상·소품 / 표정 / 포즈·구도 / 배경·조명 / 스타일·화풍 / 품질 / 미분류로 나눠 보여 줘요. 가중치(`(tag:1.2)`, `{tag}`, `1.2::tag::`), LoRA, 네거티브, 시드·스텝 같은 설정도 따로 뽑아요.
  - 태그를 누르면 다른 칸으로 옮길 수 있고, 옮긴 태그는 **내 사전**에 기억돼서 다음부터 자동으로 그 칸에 들어가요.
- **고정 프롬프트**: 기본 외형·전투복·평상복처럼 의상별로 만들어 두고, 줄마다 또는 통째로 복사해요 (SD 형식 / NovelAI 형식). 붙여넣은 프롬프트를 고정 프롬프트에 바로 반영할 수도 있어요 (포즈·표정·배경은 빼고).
- **생성 기록**: 뽑은 이미지마다 플랫폼·모델·LoRA·시드·샘플러·스텝·CFG·크기·원문 프롬프트·메모를 남기고, ★대표를 하나 고를 수 있어요. 플랫폼별로 걸러 보기도 돼요.
  - **PNG를 끌어다 놓으면 안에 든 생성 정보를 자동으로 읽어서** 기록을 채워요 (SD WebUI·Forge, NovelAI, ComfyUI). 정보가 없는 이미지는 이미지만 기록돼요.
- 왼쪽 메뉴에 **생성 도구**가 생겼어요: LoRA 목록(트리거 단어·기본 가중치·기반 모델·출처), 플랫폼·모델 목록, 내 분류 사전을 관리해요. 생성 기록에 처음 보는 플랫폼·모델 이름이 들어오면 목록에 자동으로 추가돼요.
