# 업데이트 내역

## v0.3.1 — 2026-10-15 · 앱에서도 이미지·프롬프트 보기

- 앱의 캐릭터 화면에 **이미지·프롬프트** 탭이 생겼어요. 고정 프롬프트를 의상별로 골라 보고, 줄마다 또는 통째로 복사해요 (SD 형식 / NovelAI 형식).
- 생성 기록도 앱에서 볼 수 있어요. 누르면 태그 분류와 설정을 자세히 보고 프롬프트를 복사해요. (만들고 고치는 건 아직 웹 작업실에서만 돼요.)

## v0.3.0 — 2026-10-15 · 이미지·프롬프트

- 캐릭터 화면의 **이미지·프롬프트** 탭이 열렸어요.
- **프롬프트 붙여넣기 → 자동 분류**: WebUI·Forge 생성 정보 통째로, NovelAI 태그, Midjourney 명령어를 붙여넣으면 인물·외형 / 의상·소품 / 표정 / 포즈·구도 / 배경·조명 / 스타일·화풍 / 품질 / 미분류로 나눠 보여 줘요. 가중치(`(tag:1.2)`, `{tag}`, `1.2::tag::`), LoRA, 네거티브, 시드·스텝 같은 설정도 따로 뽑아요.
  - 태그를 누르면 다른 칸으로 옮길 수 있고, 옮긴 태그는 **내 사전**에 기억돼서 다음부터 자동으로 그 칸에 들어가요.
- **고정 프롬프트**: 기본 외형·전투복·평상복처럼 의상별로 만들어 두고, 줄마다 또는 통째로 복사해요 (SD 형식 / NovelAI 형식). 붙여넣은 프롬프트를 고정 프롬프트에 바로 반영할 수도 있어요 (포즈·표정·배경은 빼고).
- **생성 기록**: 뽑은 이미지마다 플랫폼·모델·LoRA·시드·샘플러·스텝·CFG·크기·원문 프롬프트·메모를 남기고, ★대표를 하나 고를 수 있어요. 플랫폼별로 걸러 보기도 돼요.
  - **PNG를 끌어다 놓으면 안에 든 생성 정보를 자동으로 읽어서** 기록을 채워요 (SD WebUI·Forge, NovelAI, ComfyUI). 정보가 없는 이미지는 이미지만 기록돼요.
- 왼쪽 메뉴에 **생성 도구**가 생겼어요: LoRA 목록(트리거 단어·기본 가중치·기반 모델·출처), 플랫폼·모델 목록, 내 분류 사전을 관리해요. 생성 기록에 처음 보는 플랫폼·모델 이름이 들어오면 목록에 자동으로 추가돼요.

## v0.2.1 — 2026-10-15 · 한쪽짜리 성격 축

- 성격 축 편집 칸에 **안내 문구**가 생겼어요. 양 끝에 반대되는 성격(예: 내향 ↔ 외향)을 쓰고 슬라이더로 위치를 정해요.
- **오른쪽을 비워도 저장돼요.** 오른쪽이 빈 축은 한쪽 성격의 강도로 저장되고, 캐릭터 화면에 "신중함 ████░ 80%"처럼 채워진 막대와 퍼센트로 보여요. 앱에서도 똑같이 보여요.
- 오른쪽만 쓰고 왼쪽을 비우면 저장할 때 알려 줘요.

## v0.2.0 — 2026-10-15 · 장르·세계관 태그

- 프로젝트에 **장르·세계관 태그**를 붙일 수 있어요. 프로젝트 편집에서 "# 태그 고르기"를 누르면 장르, 배경·무대, 분위기·관계, 소재·설정, 게임·형식으로 나뉜 태그 130여 개가 나와요 (로맨스 판타지, 현대 판타지, 학원, 청춘, 복수, 회귀, 빙의, 캐릭터챗 …).
  - 찾기 칸으로 바로 찾을 수 있고, 없는 태그는 직접 추가할 수 있어요. 직접 추가한 태그는 팝업에서 ✕로 지워요.
- 프로젝트 목록에서 **태그로 거를 수 있어요.** 태그를 누르면 그 태그가 붙은 프로젝트만 보여요.
- 프로젝트 전용 캐릭터 화면에도 소속 프로젝트의 태그가 보여요.
- 검색에서 태그 이름으로도 프로젝트를 찾아요 (예: "로맨스" → 로맨스 판타지 프로젝트).
- **세계관 메뉴는 없앴어요.** 세계관은 프로젝트마다 설명에 쓰고, 성격은 태그로 붙여요. 이미 만든 세계관 데이터는 지우지 않고 남겨 뒀어요.
- 홈의 숫자 요약에 "세계관" 대신 "서재 캐릭터" 수가 보여요.

## v0.1.0 — 2026-10-15 · 첫 버전 (작업실)

- 처음 접속하면 서재 주인 계정을 만들어요. 그다음부터는 로그인해서 써요.
- **캐릭터**를 만들고 고칠 수 있어요: 기본 정보 칸, 성격 축, 대표 대사, 태그, 배경 이야기, 테마색, 대표 이미지.
  - 기본 정보와 대사에 🔒 비밀 표시를 할 수 있어요 (나중에 블로그를 열면 이 칸은 안 보여요).
- 캐릭터를 **프로젝트 전용**으로 두거나 **공용 서재**에 두고 여러 프로젝트에 연결할 수 있어요.
  - 서재로 꺼내기, 다른 프로젝트로 옮기기, 프로젝트용으로 분기(복사)도 돼요.
- **세계관**과 **프로젝트**(게임 · 챗봇 · 기타)를 만들고, 속한 캐릭터를 한눈에 볼 수 있어요.
- 캐릭터마다 **갤러리**에 이미지를 여러 장 올리고, 대표 이미지를 고를 수 있어요.
- 이름·소개·태그·기본 정보·대사·배경 이야기를 한 번에 **검색**해요.
- 지운 것은 **휴지통**에서 되살리거나 영구 삭제할 수 있어요.
- 밝게 / 어둡게 / 기기 설정 따라가기 화면을 고를 수 있어요.
